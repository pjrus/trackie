# Features

- Browser-only application storage with safe legacy migration
- Create, edit, delete and stage-move workflows
- Accessible pointer and keyboard Kanban drag and drop
- Sortable, horizontally scrollable table view
- Real-time search, quick filters, multi-select filters and deadline ranges
- Live active/stage summaries and deadline indicators
- Light, dark and system themes
- CSV and JSON import preview with per-row errors
- Backwards-compatible CSV and JSON export plus calendar ICS export
- Integrated guide, FAQs, CSV sample and AI prompt templates

Export JSON regularly: clearing site data can remove localStorage records.
